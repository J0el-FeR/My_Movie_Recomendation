# My Movie Recommendations
### A Movie Hobby Project

Este projeto tem como intuito mostrar um dos meus *hobby`s*, ver filmes!

Com isso em mente decidi criar um projeto que recomendasse filmes a outras pessoas, dos filmes que eu assisti e gostei.

Este projeto consiste de uma página dividida por secções onde cada secção é composta por Posters de filmes interativos, o qual é possivel navegar entre elas usando tanto o scroll do rato como um menu lateral.

- Introduction Section : Onde me introduzo e explico o meu hobby
- Movie Recommendation Section : Onde recomendo os filmes que assisti e gostei utilizando um carrossel com os posters dos filmes em uma animação contínua , o qual é possível visualizar a informação do filme ao clicar no poster, que abre o popup. Também é possível arrastar os posters no carrossel para visualizar os outros filmes que já passaram ou vão passar.
- Mystery Section : Nesta section apresento um filme de mistério da minha collection de filmes, sendo esta composta por duas cortinas e um botão no centro da página, ao clicar no botão as cortinas abrem e é revelado um poster de um filme, ao clicar no poster é aberto um popup com a informação do filme.
- Movie Collection Section : Onde apresento a minha coleção de filmes, que é composta por filmes que assisti e gostei, esta também possuindo os mesmo popups nos posters dos filmes, com uma pequena mensagem no footer.

Dentro de cada poster de filme interativo, existe o poster do filme, o título do filme, a sinopse e a avaliação no IMDB, o qual também é um botão que redireciona para a página do IMDB do filme.

Este projeto é responsivo, podendo assim ser visualizado em qualquer dispositivo, seja ele um computador, tablet ou telemóvel, onde o menu lateral fica escondido e é possivel aceder a ele através de um botão no canto superior direito da página, o resto permanece igual.
